#Description
Welcome to my Open Source Desktop CNC Router project! 

This is a fully functional, DIY 3-axis CNC machine designed for  wood, acrylic, PCBs, light aluminum. It is built around affordable and accessible components, making it a perfect project for makers and hobbyists.

Key Features:

Controller: MKS DLC32 v2.1 running GRBL/FluidNC for reliable wireless and offline control.
Power: Robust 24V system powered by a 200W Mean Well Power Supply.
Motors: Standard NEMA 17 stepper motors ] for precise movements.
Open Source: Files are provided for the community to build, modify, and improve!
Please read the Bill of Materials (BOM) carefully before starting your build.
